# docs

要件・設計に関する検討事項をまとめる場所。実装のリファレンスではなく、意思決定や構想のメモが中心。

| ディレクトリ | 内容 |
| --- | --- |
| [アーキテクチャ/](アーキテクチャ) | API・システム構成など技術的な設計方針 |
| [インフラ/](インフラ) | DB・認証・ホスティングなどインフラ構成の検討 |
| [機能アイデア/](機能アイデア) | 機能案・仕様検討のたたき台 |
| [マネタイズ/](マネタイズ) | 収益化に関するアイデア |

新しい検討事項を追加する場合は、上記のいずれかのディレクトリに追記する。該当するディレクトリがなければ新設してよい。

開発の規約・コマンドは [`CLAUDE.md`](../CLAUDE.md) と、そこの「条件付きのドキュメント」の表から当たる
[`.claude/docs/`](../.claude/docs) にある(環境・テスト・バックエンド・フロントエンド)。
