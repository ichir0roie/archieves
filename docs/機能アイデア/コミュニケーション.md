

# 組織内コミュニケーション


専用のコミュニケーションツールとして。
基本的に同じグループ間でのコミュニケーション。

たとえば、指導者とメンバーで状況を把握したり、
それぞれのスコアについて管理、統計を取ったりできるような機能。


外部とのやり取りなどは保安上の問題もあるし、本筋とは違うのでやるべきではない。

ただ、領域ごとにゆるいコミュニケーションはあってもよいだろう。




# 全国ランキングフィード

コメントやリアクションレベル。

練習の平均スコアや、
試合の記録などが個人の関連順に表示されるようになる。

# 料金プラン上の位置づけ

コミュニケーション（組織内・グループ）と全国ランキングフィードは有料機能とする。
自分の記録と自分の統計は無料。詳細は
[マネタイズ/料金プランと機能別認可.md](../マネタイズ/料金プランと機能別認可.md) を参照。
