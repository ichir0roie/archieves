# 的の種類ごとの入力テンプレート・座標のcm管理

的の種類（92cm、122cm、コンパウンド用など）ごとに入力画面のテンプレート（リング数・色）を変える。
一覧はAPI・フロント双方に固定の配列として持つ（app/core/target_types.py / scoreConfig.ts）。

タッチ入力の座標（x, y、0-1の相対値）はそのまま既存の方式で記録する。
API側でPoint保存時に、その回の的の種類（サイズ）を使って中心からの距離をcmに変換し、
x_cm/y_cmという新しいカラムに保存する。座標なし（かつての点数だけの入力の `(0, 0)`）はcmを計算しない。

# ブレの度合いの計測（メモ）

distance_m（射距離）とx_cm/y_cm（中心からのcmでのズレ）が揃っているので、
将来的にはこれらから得点のばらつき（グルーピング、ブレの度合い）を分析できそう。
